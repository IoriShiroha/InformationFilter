# 输出格式

只输出一个 JSON 对象，不要解释文字，不要使用 Markdown 代码块：

{
  "items": [
    {
      "title": "文章标题（不要带栏目名）",
      "url": "文章链接（可相对本页，但必须指向具体文章）",
      "description": "一句话摘要，没有就给空字符串",
      "picurl": "封面图链接，没有就给空字符串"
    }
  ]
}

要求：

1. 每条都必须来自页面真实内容，不要编造；找不到就少给，不要凑数。
2. 同一链接不要重复出现。
3. `url` 必须指向具体文章，不能是列表页/栏目页/首页。
